Đồng Bộ Trực Tiếp Với Google Sheets (Google Drive)

Kết nối điện thoại & máy tính vào cùng 1 bảng tính Google Sheets duy nhất.

* Khi đã cài đặt URL này, mỗi lần bạn bấm "Tạo đơn", hệ thống sẽ tự động gửi 1 dòng mới vào file Google Sheets của bạn ngay lập tức!

3 Bước Cài Đặt Đồng Bộ Google Sheets (Chỉ Làm 1 Lần Trong 1 Phút):

1 Mở Google Sheet

Mở file Google Sheets quản lý bán nước của bạn trên Google Drive. Vào thanh menu chọn Tiện ích mở rộng (Extensions) → Apps Script.

2 Dán Đoạn Code Dưới

Xóa hết mã cũ trong Apps Script, copy đoạn mã bên dưới và dán vào, sau đó bấm Lưu (Save).

3 Triển Khai (Deploy)

Bấm Triển khai (Deploy) → Triển khai mới (New deployment) → Chọn loại Web App → Ai có quyền truy cập: chọn Bất kỳ ai (Anyone) → Copy URL dán vào ô bên trên!

google_apps_script.js (Dán vào Apps Script của Google Sheets) 
function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var data = JSON.parse(e.postData.contents);
    
    // Ghi dòng mới vào Google Sheet:
    sheet.appendRow([
      data.date,
      data.invoiceNo,
      data.name,
      data.phone,
      data.location,
      data.product,
      data.qty,
      data.unitPrice,
      data.vat === 'yes' ? '8%' : '0%',
      data.total,
      data.status
    ]);
    
    return ContentService.createTextOutput(JSON.stringify({ status: "success" }))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (error) {
    return ContentService.createTextOutput(JSON.stringify({ status: "error", message: error.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
